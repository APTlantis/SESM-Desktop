# Changelog

## 0.1.0 — implementation candidate

- Independent offline Rust/Tauri desktop editor with Aptlantis-Factor interface.
- Byte-preserving SESM embedding, compatible version handling, structured/lossless JSON views, and separate validation categories.
- Local templates, explicit conflicts, per-file approval, copy-only batches, and export receipts.
- Raster-only previews with external resource isolation and documented limits.
- Source receipts, representative visual fixtures, regression tests, development packaging, and recovery documentation.
- PFX-based development package signing with automatic publisher matching, signer verification, and separate local trust installation.

Cross-platform release acceptance remains evidence-gated; see the validation record.
