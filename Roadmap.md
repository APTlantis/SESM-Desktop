# Roadmap

Implementation candidate 0.1.0 is now present. Current checks and remaining platform acceptance gates are recorded in `evidence/validation.md` and `Validation-Checklist.md`; the phases below describe the retained delivery sequence.

## Phase 1 — Data spine
Define SESM version handling, parsing, preservation, extraction, template representation, and validation behavior.

## Phase 2 — Core workflows
Implement Rust engine and Tauri UI for single-file editing, templates, batch review, and export.

## Phase 3 — Verification
Test valid/malformed/hostile SVGs, unknown fields, metadata round trips, non-destructive batch behavior, and cross-platform parity.

## Phase 4 — Release readiness
Apply DRS requirements and demonstrate a complete v0.1 workflow on Windows, Linux, and macOS.

## Evolution, not v0.1 blockers
Optional Aptlantis profiles, Chromatic Atlas pipeline integration, directory monitoring, AI assistance, and expanded distribution channels.
