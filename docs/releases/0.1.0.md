# SESM Desktop v0.1.0 — Portable, self-describing SVG assets

Implementation candidate for an independent offline SESM desktop editor. The release covers structured/lossless JSON editing, byte-preserving embedding, local templates, per-file batch approval, raster-only previews, and copy export with receipts. The interface adopts Aptlantis-Factor.

## Boundaries

No source replacement, cloud account, AI inference, theme generation, background monitoring, pipeline importer, or publication workflow. SESM is untrusted context; schema validity alone does not establish safe-profile conformance or provenance truth.

## Evidence

See `evidence/validation.md` for actual checks and platform limitations. Version identity is 0.1.0 (Windows package 0.1.0.0). Built artifact hashes are recorded by the packaging/hash scripts. Until exact shipping-artifact installation, launch, recovery, and core workflows pass on Windows, Linux, and macOS, this is not a verified cross-platform release.

The external candidate packet binds the final Windows MSIX and executable through `evidence/artifacts.json`, `SESM-Desktop.manifest.toml`, and `docs/Release-Stage-Evidence.toml`. The installer cannot embed its own final whole-file hash; packaged documentation describes the workflow while the external packet carries the final binding. The current development package is self-signed using the user's existing certificate with a matching publisher; public signing details are in `evidence/signing.json`. DRS integrity checks verify its hash; the release gate correctly rejects pending install/runtime stages.

## Recovery

Sources are unchanged. Keep exported copies and receipts; failed files can be reopened and reviewed into a new destination. Back up templates/preferences before uninstalling or resetting application data. See the bundled recovery and trust documents.
